# 51单片机学习项目

## 项目简介

本项目是一套完整的 51 单片机学习教程，以 STC89C52RC（MCS-51 内核）为核心，配套 11.0592MHz 晶振，使用 Keil C51 作为编译环境，从 GPIO 基础操作到中断、定时器、串口、显示、键盘输入逐步进阶。每个 `.c` 文件都配有极其详细的逐行中文注释，从 `#include` 到 `while(1)`，从寄存器位定义到延时函数计算过程都一一说明，适合零基础入门到进阶学习。

通过本项目的学习，你可以掌握 51 单片机的核心知识体系：IO 口准双向结构、特殊功能寄存器（SFR）、定时器/计数器、中断系统、串口通信、LCD1602 显示、矩阵键盘扫描等，并能够独立完成基于 51 单片机的小型嵌入式系统设计。

## 学习路径建议

### 第一阶段：基础入门（01_basics）
- `01_hello_led.c` - LED 闪烁实验，理解 IO 口基本操作
- `02_register_map.h` - 寄存器映射，理解 SFR 与位定义

核心知识点：
- `sbit` 关键字定义特殊功能寄存器的某一位
- 51 单片机 IO 口的准双向结构（准双向口的工作原理）
- 软件延时函数的原理与机器周期计算
- `while(1)` 死循环在嵌入式程序中的作用
- 特殊功能寄存器（SFR）的地址映射与位寻址

### 第二阶段：GPIO操作（02_gpio）
- `01_led_waterfall.c` - LED 流水灯，理解位移与循环移位

核心知识点：
- 位运算（`<<`、`>>`、`~`、`|`、`&`、`^`）在 IO 控制中的应用
- `_crol_` / `_cror_` 循环移位函数（intrins.h 库）
- `code` 关键字将数组存储到程序存储器（Flash）
- 数组段码查表法实现流水灯花型
- 流水灯的多种实现方式对比

### 第三阶段：定时器（03_timer）
- `01_timer0_basic.c` - 定时器 0 基础，理解定时中断精确延时
- `02_timer_pwm.c` - 定时器 PWM 输出，理解呼吸灯原理

核心知识点：
- 定时器/计数器的 4 种工作模式（模式 0/1/2/3）
- 定时器初值计算公式：`初值 = 65536 - 定时时间/机器周期`
- 11.0592MHz 晶振下机器周期约为 1.085us
- 定时中断实现精确延时（相比软件延时的优势）
- 软件 PWM 原理与占空比调节
- 呼吸灯的实现思路（PWM 占空比渐变）

### 第四阶段：中断系统（04_interrupt）
- `01_external_interrupt.c` - 外部中断，理解 INT0/INT1 触发
- `02_timer_interrupt.c` - 定时器中断，理解长定时与计数模式

核心知识点：
- 51 单片机的 5 个中断源（INT0、T0、INT1、T1、串口）
- 中断向量表与中断服务函数的写法（`interrupt` 关键字）
- 外部中断的两种触发方式：下降沿触发 vs 低电平触发
- 按键中断中的软件消抖处理
- 定时器中断实现 50ms 基时和 1 秒长定时的累计方法
- 计数器模式（外部脉冲计数）与定时器模式的区别

### 第五阶段：串口通信（05_uart）
- `01_uart_send.c` - 串口发送，理解 SCON 与波特率
- `02_uart_echo.c` - 串口回显，理解接收中断与命令解析

核心知识点：
- 串口控制寄存器 SCON 与缓冲寄存器 SBUF
- 波特率计算公式与常用波特率对照表
- 定时器 2 作为波特率发生器的配置方法
- 11.0592MHz 晶振下 9600bps 波特率能整除的优势
- 串口发送与接收中断的编程框架
- 字符串缓冲区与简单命令解析的实现

### 第六阶段：LCD显示（06_lcd1602）
- `01_lcd_basic.c` - LCD1602 基础，理解字符显示与光标控制

核心知识点：
- LCD1602 的初始化流程（按手册顺序写入指令）
- 4 线接法 vs 8 线接法（节省 IO 口的位拆分写入）
- DDRAM 地址与屏幕坐标的对应关系（两行各 40 字节）
- 指令写入与数据写入的区别（RS 引脚电平）
- 忙检测（读 BF）与延时等待两种处理方式
- 光标控制、清屏、回车等常用指令

### 第七阶段：键盘输入（07_keyboard）
- `01_matrix_keyboard.c` - 4x4 矩阵键盘，理解扫描与消抖

核心知识点：
- 独立按键 vs 矩阵键盘的电路结构与适用场景
- 逐行扫描法（逐行输出低电平，读取列状态）
- 行列反转法（先全行输出低读列，再全列输出低读行）
- 软件消抖（10~20ms 延时去除抖动）
- 键值映射表与按键编码的转换
- 短按 / 长按 / 连击的实现思路

## 51单片机基础知识

### STC89C52RC 主要参数
| 参数 | 说明 |
|------|------|
| 内核 | MCS-51（8051 兼容） |
| 程序存储器（Flash） | 8 KB |
| 数据存储器（RAM） | 512 字节（256B 内部 + 256B 外部扩展） |
| EEPROM | 支持（与 Flash 共享空间） |
| IO 口 | 32 个（P0、P1、P2、P3 共 4 组 8 位） |
| 定时器 | 3 个（T0、T1、T2，T2 为 16 位自动重装） |
| 外部中断 | 2 个（INT0、INT1） |
| 串口 | 1 个 UART（全双工） |
| 看门狗 | 内置看门狗定时器 |
| 工作电压 | 5V（3.3V~5.5V） |
| 最高主频 | 35MHz（常用 11.0592MHz 或 12MHz） |

### 时钟与机器周期
- 51 单片机的一个机器周期包含 12 个时钟周期
- 11.0592MHz 晶振下：机器周期 = 12 / 11.0592 ≈ 1.085 us
- **选型原因**：11.0592 = 2^7 × 3^3 × 5^2 × 768，能被常用波特率整除，使得波特率误差为 0，是 51 串口通信的事实标准晶振
- 12MHz 晶振下机器周期为 1 us，整数计算方便，但无法精确生成 9600bps 等标准波特率

### 存储器结构
- 51 单片机采用哈佛结构，程序存储器与数据存储器独立编址、独立访问
- **程序存储器（Code Space）**：存放代码与常量，`code` 关键字强制变量存放在此空间，断电不丢失
- **数据存储器（Data Space）**：存放运行时变量
  - 低 128 字节（00H~7FH）：通用 RAM，可直接/间接寻址
  - 高 128 字节（80H~FFH）：仅间接寻址（STC89C52RC 的扩展 RAM）
  - 特殊功能寄存器区（80H~FFH）：仅直接寻址，地址能被 8 整除的可位寻址
- **特殊功能寄存器（SFR）**：控制单片机各外设的窗口，如 P0~P3、TCON、TMOD、SCON、PCON、IE、IP 等

### 中断系统
- 51 单片机有 5 个中断源，2 级优先级
| 中断源 | 中断向量 | 中断号 | 触发条件 |
|--------|----------|--------|----------|
| 外部中断 0（INT0） | 0003H | 0 | P3.2 引脚下降沿或低电平 |
| 定时器 0（T0） | 000BH | 1 | T0 溢出 |
| 外部中断 1（INT1） | 0013H | 2 | P3.3 引脚下降沿或低电平 |
| 定时器 1（T1） | 001BH | 3 | T1 溢出 |
| 串口中断（UART） | 0023H | 4 | 发送完成或接收完成 |
- 中断优先级：高优先级可打断低优先级，同级中断按向量号顺序响应
- 中断服务函数写法：`void 函数名() interrupt 中断号`，编译器自动生成跳转指令

## 注意事项

### 1. 软件延时 vs 定时器延时的精度差异
- 软件延时（`for`/`while` 空循环）受编译器优化、中断打断等因素影响，精度低、不稳定
- 定时器延时由硬件计数器自动完成，不受软件流程影响，精度高、稳定可靠
- 对时间精度有要求的场合（如波特率、PWM、采样定时）必须使用定时器

### 2. 共阳 / 共阴 LED 接法的区别
- 共阳接法：LED 阳极接 VCC，IO 输出低电平点亮，**低电平有效**
- 共阴接法：LED 阴极接 GND，IO 输出高电平点亮，**高电平有效**
- STC89C52RC 上电默认 IO 输出高电平，故共阳接法上电时 LED 默认熄灭，更常用

### 3. 中断服务函数中避免复杂操作
- 中断服务函数应尽量短小精悍，只做标志位置位、缓冲区读写等轻量操作
- 避免在中断中调用复杂函数、进行浮点运算、使用大量局部变量
- 避免在中断中调用其他中断可能使用的共享资源，防止重入冲突
- 复杂逻辑放到主循环中根据中断标志位处理

### 4. code 关键字的使用场景
- `code` 关键字将变量存储到程序存储器（Flash），节省宝贵的 RAM 空间
- 适用于**只读常量**，如段码表、字模表、固定字符串等
- `code` 区变量不可在运行时修改，否则会引发未定义行为
- 51 的 RAM 仅 256~512 字节，对大数组必须使用 `code` 关键字

### 5. 11.0592MHz 晶振波特率整除的优势
- 9600bps 在 11.0592MHz 下：`初值 = 256 - 11059200 / (32 × 12 × 9600) = 253`，整除无误差
- 同样 9600bps 在 12MHz 下计算结果为 252.67，取整产生 0.16% 误差，长通信易出错
- 因此**涉及串口通信时务必使用 11.0592MHz 晶振**

## 常用引脚速查

### P0 口（P0.0~P0.7）
- 8 位准双向 IO 口，漏极开路输出，外接上拉电阻后可作为通用 IO
- 访问外部存储器时复用为数据/低 8 位地址总线

### P1 口（P1.0~P1.7）
- 8 位准双向 IO 口，内部含上拉电阻，常作通用 IO
- 本项目中常用于连接 LED 灯

### P2 口（P2.0~P2.7）
- 8 位准双向 IO 口，内部含上拉电阻
- 访问外部存储器时复用为高 8 位地址总线

### P3 口（P3.0~P3.7）复用功能表
| 引脚 | 第二功能 | 说明 |
|------|----------|------|
| P3.0 | RXD | 串口接收数据输入 |
| P3.1 | TXD | 串口发送数据输出 |
| P3.2 | INT0 | 外部中断 0 输入 |
| P3.3 | INT1 | 外部中断 1 输入 |
| P3.4 | T0 | 定时器/计数器 0 外部输入 |
| P3.5 | T1 | 定时器/计数器 1 外部输入 |
| P3.6 | WR | 外部数据存储器写选通 |
| P3.7 | RD | 外部数据存储器读选通 |
